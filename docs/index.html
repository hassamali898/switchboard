Switch less. Build more.

One Claude Code plugin that keeps Slack, Gmail, Calendar, GitHub and Jira in one quiet inbox, and adds the safety and visibility tools you wish Claude Code had: holds for risky commands, a live file tree, replay, agents and more.

Features

Eight tools. One switch each.

Every feature is separate. Turn each on or off from one pane with /sb. Coding sessions stay quiet: only what truly needs you shows up.

01Inbox/sb-inbox

Every message that matters, in one quiet list.

Slack, Gmail, Calendar, GitHub and Jira land in one color-coded list behind a bell. Coding sessions stay quiet: only what truly needs you shows above the prompt.

  • Three drafted replies (short, detailed, a question) on Haiku
  • Send with a 10 s Undo; never twice, never to the wrong person
  • Meeting cards 5 min, 1 min and at the start, with Join
02Auto rules/sb-auto

Rules in plain words. You stay in charge.

Tell the chat what to handle — "reply to Sara when she asks about the roadmap" — and Switchboard turns it into a rule you can read and switch.

  • Ask first by default: you check each action before it goes
  • Acts alone only for a person you named, under a daily cap
  • Every action is logged, most with Undo
03Files/sb-files

See what Claude reads, edits and commits.

A live file tree opens by itself while Claude works, highlights each file it touches, and closes when the turn ends.

  • Reading, edited and new files marked as they happen
  • Commits, pushes and PRs in the footer
  • Find a file, sizes, and subagent edits
04Replay/sb-replay

Every edit, step by step.

Walk through the last turns one edit at a time, with the changed words marked — and see what you changed yourself.

  • The last 3 turns, kept across sessions
  • Word-level diffs, git diffs, notebook cells
  • Previous / Next with the keyboard
05Blast Radius/sb-blast

Look before it deletes.

Commands like rm -rf, git reset --hard or git clean are held and measured first, so you see exactly what they would remove.

  • Files, sizes and what git can't restore
  • Run or Cancel; runs by itself after 1 min unless you choose
  • Never two holds at once; fails safe on any error
06Agents/sb-agents

Every subagent, live.

When Claude starts subagents, a pane shows each one's steps, model, tokens, time and cost — and closes when they finish.

  • Progress per agent and for the whole run
  • Cost and context use as they go
  • Display only: no extra model calls
07Reflect/sb-reflect

Correct Claude once.

When you correct Claude ("use pnpm, not npm"), Reflect offers to save it as a rule in CLAUDE.md — locally, without a model call.

  • For this project or all your projects
  • Reword it before saving, or decline for good
  • Saved rules apply from your next message
08Cache Tax/sb-cache

No surprise re-writes.

After a break the prompt cache goes cold, and your next message re-writes it at full price. Cache Tax holds that message and shows the cost first.

  • Send now, or start fresh with a short recap
  • The real price for your model and context
  • Keep-warm only when you ask for it
Install

Up and running in a minute.

Needs Claude Code 2.1.295 or newer and Python 3.10+. The Python environment builds itself on first use.

Switch on function hooks

In ~/.claude/settings.json, under env:

"CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1"

Install the plugin

Inside Claude Code:

/plugin marketplace add hassamali898/switchboard
/plugin install switchboard@switchboard

Open the hub

Start a new session and open Switchboard. Make one session your Inbox:

/sb
/sb-inbox here
Safety first

Built to never surprise you.

Your accounts are sensitive. Every write goes through one guarded path, and message text is always treated as data, never as instructions.

✓
Nothing sends by itselfManual sends need a click; auto sends need a saved rule, a named person and a clear request.
✓
Never twiceEach reply has an idempotency key; one that may have gone out is never retried blind.
✓
Local onlyNo server, no cloud database. Tokens live in your OS keychain.
✓
Caps and UndoDaily caps per rule, recipient checks, and an action log with Undo.
