Switch less. Build more.

One Claude Code plugin that keeps Slack, Gmail, Calendar, GitHub and Jira in one quiet inbox, and adds the safety and visibility tools you wish Claude Code had: holds for risky commands, a live file tree, replay, agents and more.

Download the beta View on GitHub

Free and open source (MIT) · Claude Code 2.1.295+ · macOS · runs entirely on your machine

Features

Eight tools. One switch each.

Every feature is separate. Turn each on or off from one pane with /sb. Coding sessions stay quiet: only what truly needs you shows up.

✉

Inbox

Slack, Gmail, Calendar, GitHub and Jira in one color-coded list behind a bell. Three drafted replies, sent with a 10 s Undo.

/sb-inbox
ϟ

Auto rules

Rules you write in plain words. Ask first by default; a reply only goes out under a saved rule, to a person you named.

/sb-auto
⏰

Meeting cards

A card before each meeting, one minute before, and at the start, with Join for the call link.

Calendar
⚠

Blast Radius

Holds rm -rf, git reset --hard and friends, measures what they'd touch, and waits for your call.

/sb-blast
▤

Files

A live tree of what Claude reads, edits and commits, opening by itself while it works.

/sb-files
↺

Replay

Step through every edit of the last turns, with word-level diffs.

/sb-replay
◎

Agents

The subagents Claude runs: progress, model, tokens and cost, live.

/sb-agents
✎

Reflect & Cache Tax

Turns your corrections into CLAUDE.md rules, and holds a costly message when the prompt cache went cold.

/sb-reflect · /sb-cache
Install

Up and running in a minute.

Needs Claude Code 2.1.295 or newer and Python 3.10+. The Python environment builds itself on first use.

Switch on function hooks

In ~/.claude/settings.json, under env:

"CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1"

Install the plugin

Inside Claude Code:

/plugin marketplace add hassamali898/switchboard
/plugin install switchboard@switchboard

Open the hub

Start a new session and open Switchboard. Make one session your Inbox:

/sb
/sb-inbox here
Safety first

Built to never surprise you.

Your accounts are sensitive. Every write goes through one guarded path, and message text is always treated as data, never as instructions.

✓
Nothing sends by itselfManual sends need a click; auto sends need a saved rule, a named person and a clear request.
✓
Never twiceEach reply has an idempotency key; one that may have gone out is never retried blind.
✓
Local onlyNo server, no cloud database. Tokens live in your OS keychain.
✓
Caps and UndoDaily caps per rule, recipient checks, and an action log with Undo.
